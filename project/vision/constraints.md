# Constraints

## Structural constraints
- Use the canonical v2 structure under `project/`.
- Use only `project/docs/priorities/` for priorities.
- Use only `project/evidence/` for evidence.

## Process constraints
- Do not leave planning state only in chat.
- Do not execute outside active-work boundaries.
- Do not treat README visibility compliance as optional.

## Scope constraints
- This framework does not control AI internals.
- This framework does not manage multiple projects in one repository instance.
