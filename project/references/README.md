# References

This directory is the local reference layer for the project.

## Purpose

Use this directory for authoritative local reference material that the project may need during planning or implementation, such as:
- language guidance
- framework guidance
- library or API notes
- platform documentation notes
- troubleshooting references
- domain-specific manuals

## Required companion files

- `index.md`
- `stack_profile.json`

## Default rule

This directory is read-oriented by default.
Normal implementation rounds should not modify this directory unless reference maintenance is explicitly authorized.
